# Marea 3D

Simulador interactivo de una turbina hidrocinética para expoferia. Permite explorar el banco en 3D, comparar rotores y materiales y estimar la potencia eléctrica al cambiar la escala o la velocidad del agua. Los resultados son simulaciones educativas.

Abre `index.html` en un navegador con WebGL. Puedes descargar el archivo y usarlo sin conexión.

## Desarrollo

Desde `desarrollo/`, ejecuta `npm ci` y `npm run dev` para trabajar en la aplicación. Con `npm run build` se genera la versión portátil en el archivo `index.html` de la raíz.
